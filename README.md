# THE UX REVIEW

A brutalist editorial blog design concept: loud typography, raw borders and an anti-polish attitude. Built as a static HTML/CSS design exercise.

**Live demo:** https://yosef-tamer206.github.io/THE-UX-REVIEW/

![THE-UX-REVIEW screenshot](docs/screenshot.png)

## Features

- Bold hero section with oversized headline
- "Trending Now" and "Latest Articles" story grids
- Article categories
- "Meet the Authors" section
- Newsletter signup block
- Responsive layout with a dedicated media-query stylesheet

## Tech Stack

- HTML5
- CSS3 (custom styles plus responsive `media.css`)
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/THE-UX-REVIEW.git
cd THE-UX-REVIEW
```

Open `index.html` in a browser.

## Notes

- A static design concept. Articles, authors and the newsletter form are sample content.
